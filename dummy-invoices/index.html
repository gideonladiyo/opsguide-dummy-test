Varian

Tambahkan query parameter untuk memicu perilaku berbeda.

?delay=N
Tombol disembunyikan, countdown N detik, lalu download otomatis. N dibatasi 1–60.
?redirect=X
Saat tombol diklik, PDF tetap terunduh lalu halaman redirect ke /dummy-invoices/X/. X salah satu dari receipt, download, billing, invoice.
?delay=N&redirect=X
Kombinasi keduanya: countdown N detik, download otomatis, lalu redirect.

Contoh: billing dengan delay 3 detik · invoice redirect ke receipt

Expected fixture: selector match = 1. File PDF valid dengan 1 halaman berisi invoice dummy.
